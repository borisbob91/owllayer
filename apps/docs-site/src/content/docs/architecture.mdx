DomOS est un SDK d'interfaces pilotées par l'IA : il permet à un agent d'agir dans une interface existante uniquement par les outils que l'application déclare. Le frontend expose le contexte utile de l'écran courant et ses outils actifs ; le serveur maintient la session et dialogue avec l'adaptateur LLM configuré.

## Flux principal : ADTP

**ADTP** (*Agent-to-DOM Transfer Protocol*) est le protocole de messages JSON transporté par WebSocket entre `DomOSClient` et `DomOSServer`. Il transporte les informations autorisées par l'application et les demandes d'action, sans donner au modèle un accès libre au DOM.

Le cycle est le suivant :

- le SDK framework utilise le runtime `DomOSClient` de `@domos/core` ;
- le client synchronise son contexte et ses outils actifs avec `CONTEXT_UPDATE` ;
- `DomOSServer` stocke cet état dans la session concernée et l'envoie à l'adaptateur LLM lorsqu'un message utilisateur arrive ;
- si le modèle demande un outil frontend, le serveur adresse `TOOL_CALL` au même client et attend son `TOOL_RESULT`.

## Les couches du système

| Couche | Package principal | Responsabilité |
| --- | --- | --- |
| Contrats partagés | `packages/core/` | ADTP, `DomOSClient`, registre des tools, HITL et états vocaux. |
| Serveur | `packages/server/` | Sessions, transport, routage, sécurité, stockage et orchestration LLM. |
| Adaptateurs de modèles | `packages/adapter-google/`, `packages/adapter-openai/` | Relier DomOS au fournisseur de modèle sélectionné. |
| SDKs UI | `packages/react/`, `vue/`, `svelte/`, `browser/` | Exposer les primitives DomOS dans l'application développeur. |
| Expérimentation | `apps/demo*` | Applications de démonstration pour les SDKs. |
| Documentation | `apps/docs-site/` | Documentation publiée avec Astro et Starlight. |

## Ce qui traverse les couches

Le contexte d'interface n'est pas une autorisation d'agir. Les données exposées aident le modèle à comprendre la situation ; seuls les outils déclarés définissent les actions qu'il peut demander. Le serveur applique ensuite l'authentification, la limitation de trafic et le contrôle HITL avant le routage d'un appel.
