## Une interface pilotée par l'IA, sous contrôle

**DomOS est un SDK d'interfaces pilotées par l'IA** (*AI-driven interfaces*). DomOS permet à un agent IA d'agir dans une interface existante par des actions que le développeur déclare explicitement.

L'application conserve sa logique métier et ses garde-fous ; l'agent reçoit seulement le contexte utile et les outils disponibles sur l'écran courant. DomOS n'est donc pas une interface générée par le modèle, ni un accès automatique au DOM.

## Le principe

Une application DomOS reste une application web ordinaire : elle possède ses composants, ses données et ses services. Elle ajoute un contrat explicite pour l'agent :

- le **contexte** décrit uniquement les informations utiles de l'écran courant ;
- les **outils** (`tools`) décrivent les actions que l'agent peut demander ;
- **ADTP** transporte le contexte, les appels d'outils et leurs résultats ;
- **HITL** permet d'exiger une approbation humaine avant une action sensible.

L'agent n'obtient donc pas le pouvoir de modifier arbitrairement l'application. Il utilise les possibilités que le développeur a choisies, décrites et sécurisées.

## Pour les développeurs

Les SDK React, Vue, Svelte, Angular et Browser offrent des intégrations adaptées à chaque environnement. Ils reposent sur le même runtime client et le même protocole : le modèle de contrôle reste identique quel que soit le framework utilisé.
